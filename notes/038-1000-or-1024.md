# 038: 1000 or 1024, why your drive looks smaller than the box said
builds on: [004 bytes, 8 bits and 256 possible values](./004-bytes.md), [003 counting in binary](./003-counting-in-binary.md), [033 kilobytes to terabytes, how big data gets](./033-kilobytes-to-terabytes.md)
section: memory, disks and files, part 4, ~2 min read

you buy a 500 GB drive, plug it into a windows laptop, and it says 465. where did the other 35 GB go?

nowhere. two tools are counting with different rulers. the box uses the metric way from [033](./033-kilobytes-to-terabytes.md), where a gigabyte (GB) is a billion [bytes](./004-bytes.md), the 8 bit units files are counted in. windows counts in steps of 1024 instead, but still writes "GB".

why 1024? doubling 1 ten times, the [binary](./003-counting-in-binary.md) counting where each place is worth double, lands on 1024, close enough to 1000 that people borrowed kilo, the metric word for thousand. the clear names add an i, kibibyte (KiB, 1024 bytes), then mebibyte, gibibyte (GiB) and tebibyte, each 1024 times the last.

the same byte counts, both rulers, side by side:

```python
for step, name in enumerate(["KB", "MB", "GB", "TB"], 1):
    box, binary = 1000 ** step, 1024 ** step
    print(f"{name}: {box:>16,} vs {binary:>16,}  ({box / binary:.1%})")
print("500 GB box =", round(500 * 1000 ** 3 / 1024 ** 3, 1), "GiB")
```

```output
KB:            1,000 vs            1,024  (97.7%)
MB:        1,000,000 vs        1,048,576  (95.4%)
GB:    1,000,000,000 vs    1,073,741,824  (93.1%)
TB: 1,000,000,000,000 vs 1,099,511,627,776  (90.9%)
500 GB box = 465.7 GiB
```

the percentage is the box number as a share of the 1024 one, so the gap grows, 2.3 percent off at KB, about 9 percent at TB. i assumed the missing space was lost to overhead, but the bytes are all there, just divided by a bigger number. the shop, the imaginary snack store these notes run on, had 35 TB of orders in 033, which reads 31.8 on a 1024 tool.

macOS displays decimal and windows displays 1024 while keeping the GB label, so the same drive says 500 on a mac. in 033 i said some tools count 1024, this is the fuller picture, and when it matters, look for the i in GiB.
